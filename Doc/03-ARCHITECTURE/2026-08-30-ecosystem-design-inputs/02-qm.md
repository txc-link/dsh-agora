## §1 已确认的设计 / 事实

- **身份**: Y Combinator 自研的 multiplayer agent harness, 当前替代 YC 内部 50+ 个独立运行的 Hermes agents
- **仓库**: `github.com/yc-software/qm`, 创建 2026-07-29, release v0.1.4 (2026-07-31), 到 2026-08-04 ≈ 9,700 stars
- **License**: MIT
- **部署目标**: Fly.io 或 AWS (org 自有 account), 不要求 SaaS 接入
- **Model drivers** (share same core contract): Pi / OpenCode / Codex / Claude Code — 抽象=可换
- **核心 primitive = Scope (不是 Chat)**:
  - 4 个作用域: Personal / Room / Group / Project
  - 每个 scope 持有: memory, files, keychain view, permissions, scheduled work, web apps, durable sandbox
- **三种 security posture (org-level)**:
  - **Strict**: 几乎每个 harness tool call 都暂停请求人类批准
  - **Auto** (default): classifier 屏幕 provenance-labeled 外部文本 + tool results
  - **Dangerous**: 移除 content screening, 在 tool calls 之间暂停
  - 三者共同: declared command policy + 破坏性 ops 硬拒绝
- **七步执行路径**:
  1. user starts conversation (web/Slack)
  2. core resolves principal + scope (personal/room/group/project)
  3. posture + scope policy 决定 proceed / narrow tools / wait human approval
  4. harness + model 产出 response
  5. tools 在 scope 的 durable sandbox 跑 (authorized files + credential grants)
  6. core 返回 result + 存 session/tool/security records
  7. operators 用 audit trail 调查
- **权限模型**:
  - scope-authorized org administrator = privileged content reader (无需 separate user consent; audited)
  - regular member 受 scope + grants 约束
- **Durable sandbox**:
  - 持久化省 setup time (tools + files 跨 turn 存活)
  - 风险: 默认捕获 exact model request; file artifacts 无 expiry; file writes 无 secret scan; org-wide kill switch 不完整
  - 7-day cooldown: 新发布 npm dep 版本 7 天后才允许进 lockfile
- **Trust model**:
  - "Authenticated users inside one organization" (不是 hardened public multi-tenant boundary)
  - 发布的 web app 用单独 bearer capability link (anyone with link 可访问直到 auth 变化)

## §3 借鉴决策 (§1.5 first-principles)

- **可借鉴 — Scope-as-first-class**: QM 明确把 scope (personal/room/group/project) 作为 turn resolution 的第一抽象; Agora 已通过 WorkSite 类型 (task/thread/commit/watch/workspace/session) 表达类似分层, 但没 QM 那么显式. 可考虑: 在 WorkSite 上挂 explicit `scope-authorization` 字段 (project vs room vs personal)
- **可借鉴 — Three-posture model (Strict/Auto/Dangerous)**: 跟 turn 25 §"受控" 完美对齐; Agora 当前 ACL 是 per-task approve, 缺 org-level posture. 三 posture 比单一 per-task 审批更可调, 适合 24×7 + 维护 + 受控 三维同时满足
- **可借鉴 — Audit trail by default**: QM 每个 turn 都存 session/tool/security records, Agora 已有 audit log 但**没**默认启用. 这是低风险高 ROI: 升级默认 + 一次性改造审计存储
- **可借鉴 — Durable sandbox**: Agent 跨 turn 保留 file state, 跟 Phase 1 WorkSite (worksite/session type) 有交集. 借鉴点: 不要每次 turn 重 setup, 维护 warm state
- **不借鉴 — core replacement 策略**: QM 用 Pi/OpenCode/Codex/ClaudeCode 共享同一 contract; Agora §1 锁用 adapter 模式隔离 runtime. 两种思路都符合 §1, 但 Agora 已 settled, 不重新设计
- **不借鉴 — Slack 作为 primary surface**: QM 把 Slack 当主入口; Agora 中央是 task orchestrator (不绑 IM). 顶层架构不变
- **不借鉴 — 7 天 npm cooldown**: 这是 supply chain 控制, 跟 Agora 编排核心无关. 退耦, 不借鉴

## §4 跟 Agora 已落地 Phase 1 的差异 + Phase 2 含义

- **Phase 1 WorkSite = 抽象层 URI**, 没绑 QM 的 "scope as principal"
  - 影响: 现在 WorkSite 是 passive storage; Phase 2 让它成为 turn resolution 的主语 (像 QM scope 那样)
- **Phase 2 (matrix-connector @pull) 设计含义**
  - matrix 多 Room 模拟 thread 已经隐式支持 scope (每 Room = 1 scope)
  - 但需要加 explicit `scope-authorization` 字段 (e.g. matrix_room_id → scope.project)
  - Phase 2 落点: cc-connect adapter 同时输出 scope, 不只是 thread
- **Phase 3+ (Agent borrow)**
  - QM 用 principal + scope 表达 "谁能 let agent 做什么"
  - Agora U3/U4 是同方向但还没决议 — QM 三 posture 可作 §3 候选之一
- **关键 takeaway**
  - QM 的 Scope 设计 = **Agora 的 WorkSite + 借用权限 + 组织 posture 的三位一体**
  - 三者任何缺一, 就达不到 QM 同等的 "有组织的 24×7 主动协同"
  - 推荐 Phase 2 起把三者一起规划, 不分批割裂 (跟 §1.5 "最短实现路径" 对齐)

## §5 风险 / 限制 (per QM 自己 + Tent.co 评估)

- shell-text command policy 可被 obfuscation/encoding bypass — classifier 是启发式, 不完备
- browser-runner actions 不一定回 command policy — 走的是另一条 audit 路径
- Auto classifier 只 cover 部分 command results / multimodal / raw webhook — 没全 cover
- credentials materialize as plaintext in env var 或 file — sandbox 内 compromised process 可 spend
- file artifacts no expiry; secret scanning on file writes absent; org-wide kill switch incomplete — 三处未完成
- 管理员 = privileged content reader (没 separate user consent) — 内部 threat model 强假设
- MIT license ≠ zero-cost — infrastructure / model usage / security review 都要预算
